# Documentation entry point for coding agents

The repository-wide instructions are in [`../AGENTS.md`](../AGENTS.md). Read them first.

For the current worktree and exact verification state, read [`STATUS.md`](STATUS.md). Then use the source maps in [`ARCHITECTURE.md`](ARCHITECTURE.md), [`PREVIEW_PIPELINES.md`](PREVIEW_PIPELINES.md), [`FILE_FORMATS.md`](FILE_FORMATS.md), [`DATABASE.md`](DATABASE.md), and [`SECURITY.md`](SECURITY.md) as navigation aids. Source code remains authoritative if a document and implementation ever disagree.

Do not use archived loop prompts, old worklogs, stale release notes, or old build logs as proof of current behavior. Keep future documentation in English, update the source-of-truth page for the behavior being changed, and record command output and toolchain blockers in `STATUS.md`.
